# skills

Personal collection of agent skills.

## Install

Copy or symlink any folder inside `skills/` into your agent's skills directory, or install all skills with `npx` or `bunx`:

```bash
npx skills add LightAndy1/agent-skills
bunx skills add LightAndy1/agent-skills
```

## Skills

### elic

Short, plain language explanations without technical jargon or talking down (`/elic`). See [SKILL.md](skills/elic/SKILL.md).

```bash
npx skills add LightAndy1/agent-skills --skill elic
bunx skills add LightAndy1/agent-skills --skill elic
```

### hommit

Git commits grouped by category with casual, lowercase messages (`/hommit`). See [SKILL.md](skills/hommit/SKILL.md).

```bash
npx skills add LightAndy1/agent-skills --skill hommit
bunx skills add LightAndy1/agent-skills --skill hommit
```

### noemi

Remove em dashes, en dashes, and visible dashes from copy shown to users (`/noemi`). See [SKILL.md](skills/noemi/SKILL.md).

```bash
npx skills add LightAndy1/agent-skills --skill noemi
bunx skills add LightAndy1/agent-skills --skill noemi
```
