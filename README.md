# skills

Personal collection of agent skills.

## Included

- [`skills/elic`](skills/elic/SKILL.md): Plain-language explanations without jargon or talking down (`/elic`).
- [`skills/noemi`](skills/noemi/SKILL.md): Remove em dashes, en dashes, and visible dashes from user-facing copy (`/noemi`).

## Install

Copy or symlink any folder inside `skills/` into your agent's skills directory, or install with `npx skills`:

```bash
npx skills add <owner>/<repo>
```
